# موقع الأستاذة سناء الخفاجي
موقع تعريفي عربي متجاوب بتصميم زجاجي وألوان كحلية وذهبية وتركوازية.

## التفعيل
- تم إعداد الموقع كملفات ثابتة متوافقة مع GitHub Pages.
- من إعدادات المستودع: Settings → Pages → Build and deployment → Deploy from a branch.
- اختر الفرع main والمجلد /(root)، ثم Save.
- الرابط المتوقع: https://baghdad-i.github.io/sanaa-physics/

## قبل مشاركة الموقع
استبدل رقم واتساب التجريبي 9647XXXXXXXXX برقم الأستاذة بصيغة دولية دون علامة + أو مسافات، واستبدل your_username باسم حساب إنستغرام. استبدل خانات آراء الطلبة بشهادات حقيقية وبموافقة أصحابها.
